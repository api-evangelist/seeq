# Seeq

> Seeq is an industrial analytics, machine learning and AI platform for time-series and process manufacturing data. It combines operational data with employee expertise and historical context to speed decisions across process industries. Programmatic access is via the Seeq Server REST API (served per instance at /api with an interactive Swagger surface) and the official Python modules `seeq` and `seeq-spy` (SPy).

## APIs
- [Seeq Server REST API](https://python-docs.seeq.com/): Per-instance REST API at /api; authenticated via access keys, username/password (authentication directory), or OAuth 2.0 / SSO.

## SDKs & Packages
- [seeq (PyPI)](https://pypi.org/project/seeq/): Official Python module for the Seeq Server REST API; version mirrors Seeq Server (66.167.0.20260720).
- [seeq-spy (PyPI)](https://pypi.org/project/seeq-spy/): Official SPy module, Pandas/NumPy/Jupyter-optimized (202.2); requires a Seeq Data Lab license.
